# Linear Regression From Scratch

This project implements Linear Regression from scratch using Python and NumPy. The model learns the relationship between input features and target values by optimizing parameters (slope and intercept) using mathematical concepts rather than pre-built machine learning models.

## Features
- Linear Regression from scratch
- Cost function implementation
- Gradient Descent optimization
- Prediction on new data
- No use of Scikit-learn's LinearRegression model

## Technologies Used
- Python
- NumPy
- Pandas
- Jupyter Notebook
